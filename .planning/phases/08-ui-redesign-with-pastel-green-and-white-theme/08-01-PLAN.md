# Plan 08-01: Design Tokens, Global CSS & Workspace Shell Redesign

## Objective
Xây dựng nền tảng Design System chuẩn mực cho toàn bộ ứng dụng qua hệ thống CSS Variables trong `globals.css` theo bảng màu Trắng tinh khiết & Xanh lá Pastel (Sage & Mint `#10b981`, `#ecfdf5`, `#047857`), typography hiện đại, viền mỏng và đổ bóng vi mô; tái thiết kế hoàn chỉnh thanh điều hướng `Sidebar.tsx`, bố cục App Shell `(workspace)/layout.tsx` (kèm mobile drawer), và các trang xác thực (`login/page.tsx`, `change-password/page.tsx`).

<acceptance_criteria>
- `frontend/src/components/Sidebar.tsx` sử dụng nền trắng (`#ffffff`), viền mỏng (`#e2e8f0`).
- `Sidebar.tsx` hiển thị Logo SVG với icon logistics/AI xanh pastel (`#10b981`), tên "Logistics RAG" và badge "v1.0" nhỏ gọn.
- `Sidebar.tsx` hiển thị thẻ người dùng cố định ở đáy với avatar tròn viết tắt chữ cái nền pastel mint, tên tài khoản và pill badge vai trò (`Quản trị viên` / `Kỹ thuật viên`).
- `(workspace)/layout.tsx` hỗ trợ thanh Header di động với nút Hamburger mở/đóng Sidebar trên mobile/tablet (`max-width: 768px`) kèm nền mờ backdrop.
</acceptance_criteria>

<action>
1. Tái cấu trúc `frontend/src/components/Sidebar.tsx`:
   - Nền trắng tinh gọn (`background: #ffffff; border-right: 1px solid var(--border-subtle)`).
   - Logo thương hiệu ở đầu: Icon SVG chiếc hộp logistics phát sáng nhẹ kèm mạng lưới AI, chữ "Logistics RAG" đậm nét và badge `v1.0` pastel.
   - Menu điều hướng: Các liên kết `Hỏi đáp Tri thức (/chat)`, `Quản trị Dataset (/datasets)`, `Phân tích Sự cố (/incidents)`, `Báo cáo Định kỳ (/reports)`, `Cấu hình Mô hình (/configuration)`, `Tài khoản (/accounts)`. Item active có nền `var(--color-pastel-mint)`, chữ `var(--color-emerald-dark)`, và vạch active 3px màu `#10b981` ở mép trái.
   - Chân Sidebar: Thẻ người dùng bo góc chứa avatar tròn viết tắt tên, nhãn vai trò pill badge pastel (`Quản trị viên` / `Kỹ thuật viên`), và nút "Đăng xuất" thanh lịch.
2. Tái cấu trúc `frontend/src/app/(workspace)/layout.tsx`:
   - Bố cục flex 2 cột trên desktop.
   - Thêm Header di động trên mobile hiển thị logo thu nhỏ và nút Hamburger icon.
   - Overlay backdrop mờ khi Sidebar mở dạng Drawer trên thiết bị di động.
</action>
