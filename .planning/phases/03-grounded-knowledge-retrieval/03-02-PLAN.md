<threat_model>
### Threat Assessment (ASVS L1)
- **T-03-04 (Stale / Deleted Data Retrieval):** Bản ghi của nguồn đã bị xóa (tombstone) hoặc phiên bản cũ không còn active vẫn xuất hiện trong vector search dẫn đến lộ dữ liệu trái phép.
  - *Mitigation:* Đồng bộ hóa việc xóa `embedding_records` khi gọi `tombstone_source()` và lọc `Source.deleted_at IS NULL` cùng `Source.active_version_id` trong câu lệnh SQL truy xuất.
- **T-03-05 (Admin Config Secret Exposure):** Endpoint `/api/v1/config/models` vô tình trả về raw OpenAI API key cho client.
  - *Mitigation:* API DTO `ModelConfigDTO` chỉ trả về thông tin `is_configured: bool`, `model_name`, `dimension`, `index_version`; che dấu hoàn toàn giá trị key.
</threat_model>

<name>03-02-01: Vector Indexing Service & Canonical Record Embedding Pipeline</name>
<files>backend/app/rag/embeddings.py, backend/app/workers/tasks.py, backend/tests/integration/test_vector_indexing.py</files>
<read_first>backend/app/database/models.py, backend/app/rag/contracts.py, backend/app/llm/secret_masking.py, backend/app/providers/fake.py</read_first>
<action>
1. Tạo `backend/app/rag/embeddings.py`:
   - Class `VectorIndexingService`:
     - Khởi tạo với `EmbeddingProvider` và `index_version: UUID` (hoặc cấu hình từ env/db).
     - Method `index_source_version(db: Session, source_version_id: UUID) -> int`:
       - Truy vấn toàn bộ `CanonicalRecord` thuộc `source_version_id`.
       - Áp dụng `mask_secrets(record.content_text)` trước khi gửi embedding (đảm bảo SYS-03).
       - Gom batch văn bản (tối đa 100 đoạn mỗi batch) và gọi `provider.embed_texts(batch_texts)`.
       - Xóa các `EmbeddingRecord` cũ của `source_version_id` (nếu có để bảo đảm idempotency).
       - Chèn các dòng `EmbeddingRecord` mới vào database với vector 1536 chiều, lưu `canonical_record_id`, `dataset_id`, `source_version_id`, `model_name`, `dimension`, `index_version`.
       - Trả về tổng số vector đã index.
     - Method `delete_source_embeddings(db: Session, source_id: UUID) -> int`:
       - Xóa toàn bộ `EmbeddingRecord` thuộc các `source_version_id` của `source_id`.
2. Bổ sung task Celery vào `backend/app/workers/tasks.py`:
   - Task `index_source_version_task(source_version_id_str: str)`:
     - Mở session DB, khởi tạo `VectorIndexingService`, gọi `index_source_version`.
     - Ghi log tiến trình và số lượng record đã lập chỉ mục.
3. Viết test `backend/tests/integration/test_vector_indexing.py`:
   - Nạp canonical records mẫu, chạy `index_source_version` với `FakeEmbeddingAdapter`.
   - Xác minh số lượng dòng trong `embedding_records` khớp chính xác với `canonical_records`.
   - Kiểm tra metadata `model_name`, `dimension`, `index_version` được lưu đúng.
</action>
