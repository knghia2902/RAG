<threat_model>
### Threat Assessment (ASVS L1)
- **T-03-01 (Secret Leakage in Egress / Logs):** Khóa API OpenAI, chuỗi kết nối hoặc thông tin nhạy cảm có thể bị vô tình nhúng vào vector chunk hoặc prompt context gửi ra ngoài.
  - *Mitigation:* Bắt buộc chạy qua `mask_secrets()` trong `app.llm.secret_masking` trước khi gửi query hoặc context qua OpenAI API; kiểm thử với fixture khóa mẫu (sk-*, Bearer, API keys).
- **T-03-02 (SQL / DDL Injection in Vector Schema):** Extension `vector` hoặc truy vấn index có thể bị lỗi cú pháp hoặc SQL injection nếu không tham số hóa.
  - *Mitigation:* Sử dụng migration Alembic chuẩn hóa với type `pgvector.sqlalchemy.Vector(1536)` và index ivfflat/hnsw cố định thông qua SQLAlchemy DDL.
- **T-03-03 (Architectural Boundary Violation):** Import trực tiếp `openai` hoặc `langchain` vào `app.rag` hay `app.llm` sẽ phá vỡ kiến trúc cô lập adapter.
  - *Mitigation:* Tuân thủ bài test `backend/tests/unit/test_module_boundaries.py`, chỉ đặt import third-party SDK trong `backend/app/providers/`.
</threat_model>
