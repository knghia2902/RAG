<threat_model>
### Threat Assessment (ASVS L1)
- **T-03-10 (Time-of-Check to Time-of-Use / Revoked Grant Leak):** Người dùng mở lại cuộc trò chuyện cũ hoặc bấm vào citation của một dataset mà quyền đã bị Admin thu hồi 5 phút trước.
  - *Mitigation:* Bắt buộc gọi `recheck_response(db, account, {dataset_id})` trong mọi request lấy chi tiết citation hoặc lịch sử tin nhắn; trả về 403 Forbidden kèm thông báo an toàn, không gửi text nguồn (D-05).
- **T-03-11 (Cross-Account Session Hijacking):** Người dùng A cố tình đoán ID phiên chat của người dùng B (`/api/v1/chat/sessions/{id}`).
  - *Mitigation:* Truy vấn phiên chat luôn lọc theo `ChatSession.account_id == account.id`; nếu không khớp trả về 404 Not Found.
</threat_model>

<action>
1. Bổ sung DTO vào `backend/app/api/schemas.py`:
   - `ChatSessionDTO`: `id: UUID`, `title: str`, `created_at: datetime`, `updated_at: datetime`
   - `ChatMessageDTO`: `id: UUID`, `role: str`, `content: str`, `citations: list[dict]`, `has_uncertainty: bool`, `has_conflict: bool`, `created_at: datetime`
   - `ChatQueryRequestDTO`:
     - `question: str` (min_length=1, max_length=2000)
     - `session_id: UUID | None = None`
     - `dataset_ids: list[UUID] | None = None`
     - `profile_id: str | None = None`
     - `start_time: datetime | None = None`
     - `end_time: datetime | None = None`
   - `ChatQueryResponseDTO`: `session_id: UUID`, `message: ChatMessageDTO`, `citations: list[dict]`
   - `CitationPreviewResponseDTO`: `citation_index: int`, `dataset_name: str`, `logical_filename: str`, `version_number: int`, `locator: SourceLocatorDTO`, `excerpt_text: str`
2. Tạo `backend/app/api/chat.py`:
   - Router prefix `/api/v1/chat`:
     - `GET /sessions`: Lấy danh sách session của `current_account(db, account)`.
     - `POST /sessions`: Tạo session mới với tiêu đề mặc định hoặc tự sinh.
     - `DELETE /sessions/{session_id}`: Xóa session và tin nhắn (chỉ cho phép chủ sở hữu session).
     - `GET /sessions/{session_id}/messages`: Lấy danh sách tin nhắn. Tự động lọc bỏ trích dẫn của các dataset đã mất quyền truy cập.
     - `POST /query`:
       - Kiểm tra session_id (tạo mới nếu None).
       - Tính scope cho phép: `allowed = allowed_dataset_ids(db, account)`.
       - Lọc theo `request.dataset_ids` giao với `allowed`. Nếu rỗng -> báo lỗi 403 hoặc thông báo phạm vi.
       - Gọi `HybridRetriever.retrieve()` trong phạm vi được cấp quyền.
       - Gọi `GroundedGenerator.generate_answer()` với danh sách bằng chứng thu được.
       - Lưu tin nhắn người dùng và tin nhắn AI vào `chat_messages`.
       - Cập nhật `updated_at` và `title` của `chat_sessions`.
       - Trả về `ChatQueryResponseDTO`.
     - `GET /citations/preview`:
       - Nhận query params: `dataset_id: UUID`, `source_id: UUID`, `record_id: UUID`.
       - Live Scope Recheck (D-05): Gọi `recheck_response(db, account, {dataset_id})`. Nếu mất quyền, ném `HTTPException(403, "Quyền truy cập nguồn dữ liệu đã thay đổi hoặc bị thu hồi.")`.
       - Trả về `CitationPreviewResponseDTO` kèm text nguyên bản và locator.
3. Đăng ký router `/api/v1/chat` vào `backend/app/main.py`.
4. Viết integration test `backend/tests/integration/test_chat_api.py` và `test_live_scope_recheck.py`:
   - Kiểm tra luồng gửi câu hỏi và nhận câu trả lời có trích dẫn.
   - Kiểm tra live scope recheck: cấp quyền dataset cho Tech -> hỏi đáp thành công -> Admin thu hồi quyền dataset -> Tech gọi lấy preview citation -> nhận ngay mã lỗi 403 Forbidden.
</action>
