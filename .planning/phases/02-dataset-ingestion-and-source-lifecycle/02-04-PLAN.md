<action>
1. Mở rộng `backend/app/api/schemas.py` bổ sung các DTO bất biến kế thừa `DTO` (tuân thủ `model_config = ConfigDict(extra="forbid", frozen=True)`):
   ```python
   class SourceProfileDTO(DTO):
       id: str
       name: str
       description: str
       supported_formats: list[str]
       expected_fields: list[str]
       optional_fields: list[str]

   class SourceVersionDTO(DTO):
       id: UUID
       version_number: int
       content_hash: str
       size_bytes: int
       mime_type: str
       created_at: datetime

   class IngestionJobDTO(DTO):
       id: UUID
       source_version_id: UUID
       state: str
       attempt_count: int
       error_code: str | None = None
       error_message: str | None = None
       diagnostics: list[dict[str, Any]] | None = None
       created_at: datetime
       updated_at: datetime

   class SourceDTO(DTO):
       id: UUID
       dataset_id: UUID
       logical_filename: str
       profile_id: str
       active_version_id: UUID | None = None
       active_version_number: int | None = None
       status: str
       error_message: str | None = None
       created_at: datetime
       updated_at: datetime

   class SourcePage(DTO):
       items: list[SourceDTO]
       total: int
       page: int
       page_size: int

   class UploadResultItemDTO(DTO):
       filename: str
       source_id: UUID
       version_number: int
       status: str
       job_id: UUID
       is_duplicate: bool
       message: str

   class UploadBatchResponseDTO(DTO):
       items: list[UploadResultItemDTO]

   class SourceLocatorDTO(DTO):
       source_id: UUID
       source_version: int
       page: int | None = None
       section: str | None = None
       sheet: str | None = None
       row: int | None = None
       event: int | None = None
       record: int | None = None
       line_start: int | None = None
       line_end: int | None = None
       json_path: str | None = None

   class EvidenceExcerptDTO(DTO):
       id: UUID
       position: int
       text: str
       locator: SourceLocatorDTO
       metadata: dict[str, Any] = Field(default_factory=dict)

   class EvidencePreviewPage(DTO):
       source_id: UUID
       version_number: int
       items: list[EvidenceExcerptDTO]
       total: int
       page: int
       page_size: int
   ```
2. Cập nhật `backend/tests/unit/test_module_boundaries.py` kiểm tra:
   - Các DTO mới tuân thủ `extra="forbid"` và `frozen=True`.
   - Không lộ các thuộc tính nhạy cảm như `storage_key` hay đường dẫn server trong DTO.
</action>

1. Tạo `backend/app/api/sources.py`:
   - Định nghĩa `router = APIRouter(prefix="/api/v1", tags=["sources"])`.
   - `GET /datasets/{dataset_id}/sources/profiles`:
     - Trả về danh sách 5 hồ sơ nguồn khả dụng (`SourceProfileDTO`).
   - `POST /admin/datasets/{dataset_id}/sources/upload`:
     - Bảo vệ bởi `Depends(mutation_manager)` (yêu cầu Admin, CSRF hợp lệ, Origin hợp lệ) và `Depends(get_db)`.
     - Nhận `profile_id: str = Form(...)` và `files: list[UploadFile] = File(...)`.
     - Giới hạn kích thước: Cảnh báo/từ chối tệp vượt quá 50MB hoặc batch vượt quá 10 tệp.
     - Kiểm tra đuôi file có thuộc `supported_formats` của `profile_id` hay không.
     - Lặp qua từng file, gọi `database.sources.save_uploaded_source()`.
     - Trả về `UploadBatchResponseDTO(items=[...])` chứa kết quả riêng của từng file.
   - `GET /datasets/{dataset_id}/sources`:
     - Nhận `account = Depends(get_account)`, `db = Depends(get_db)`, `page: int = Query(1, ge=1)`, `page_size: int = Query(25, ge=1, le=100)`.
     - Kiểm tra quyền truy cập dataset của tài khoản hiện tại qua `allowed_dataset_ids(db, account)`. Nếu không có quyền, ném `HTTPException(404, "Không tìm thấy Dataset")`.
     - Truy vấn các nguồn chưa bị xóa (`deleted_at IS NULL`) thuộc `dataset_id`.
     - **Tái kiểm tra quyền (Live Scope Recheck):** Gọi `recheck_response(db, account, {dataset_id})` ngay trước khi trả kết quả `SourcePage`.
   - `GET /datasets/{dataset_id}/sources/{source_id}`:
     - Nhận `account = Depends(get_account)`, `db = Depends(get_db)`.
     - Kiểm tra quyền và gọi `recheck_response`. Trả về `SourceDTO`.
   - `GET /datasets/{dataset_id}/sources/{source_id}/preview`:
     - Nhận `account = Depends(get_account)`, `db = Depends(get_db)`, `page: int = Query(1, ge=1)`, `page_size: int = Query(25, ge=1, le=100)`.
     - Kiểm tra quyền dataset.
     - Truy vấn `Source`. Nếu `source.deleted_at IS NOT NULL` hoặc `source.active_version_id IS NULL`, ném `HTTPException(404, "Nguồn không khả dụng hoặc chưa có phiên bản sẵn sàng")`.
     - Lấy các bản ghi `CanonicalRecord` của `source.active_version_id`.
     - **BẢO MẬT TUYỆT ĐỐI (D-08, ASVS V14):** Chỉ trả về nội dung trích xuất `text` và `locator`. Tuyệt đối KHÔNG trả về `storage_key`, đường dẫn tệp server, hay URL công khai.
     - Gọi `recheck_response(db, account, {dataset_id})` ngay trước khi trả kết quả `EvidencePreviewPage`.
   - `POST /admin/datasets/{dataset_id}/sources/{source_id}/retry`:
     - Bảo vệ bởi `Depends(mutation_manager)`, `Depends(get_db)`.
     - Gọi `database.sources.retry_failed_job()`. Trả về `IngestionJobDTO`.
   - `POST /admin/datasets/{dataset_id}/sources/{source_id}/reprocess`:
     - Bảo vệ bởi `Depends(mutation_manager)`, `Depends(get_db)`.
     - Gọi `database.sources.reprocess_active_source()`. Trả về `IngestionJobDTO`.
   - `DELETE /admin/datasets/{dataset_id}/sources/{source_id}`:
     - Bảo vệ bởi `Depends(mutation_manager)`, `Depends(get_db)`.
     - Gọi `database.sources.tombstone_source()`. Trả về `{}` (HTTP 200/204).
2. Trong `backend/app/main.py`:
   - Import `sources` từ `app.api`.
   - Đăng ký `app.include_router(sources.router)`.
3. Trong `backend/tests/integration/test_sources.py` và `backend/tests/integration/test_source_access.py`:
   - Kiểm tra Admin upload thành công tệp hợp lệ và nhận kết quả batch.
   - Kiểm tra Kỹ thuật viên bị từ chối 403 khi gọi upload, retry, reprocess, delete.
   - Kiểm tra Kỹ thuật viên được cấp quyền dataset có thể xem danh sách nguồn và xem preview.
   - Kiểm tra Kỹ thuật viên không có quyền dataset bị trả về 404/403 và không xem được dữ liệu.

<threat_model>
ASVS 5.0.0 Level 1; các hạng mục áp dụng:
## Trust Boundaries
| Boundary | Description |
|---|---|
| Client Multipart Upload → FastAPI Endpoint | Kiểm tra kích thước tệp, số lượng tệp trong batch, CSRF và Origin |
| Authenticated User → Preview Endpoint | Kiểm tra quyền truy cập dataset và tái kiểm tra scope SQL thời gian thực |
| Storage Key → API Response | Ngăn chặn lộ đường dẫn vật lý cục bộ hoặc URL truy cập tĩnh |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-04-E | Elevation of privilege | upload route authorization | high | mitigate | Endpoint upload được bảo vệ bởi `mutation_manager` (bắt buộc role Admin và CSRF token) |
| T-02-04-A | Authorization bypass | mid-request permission revocation | high | mitigate | Áp dụng `recheck_response` ngay trước khi serialize và trả về DTO preview |
| T-02-04-I | Information disclosure | internal filesystem path leak | high | mitigate | Response schema chỉ chứa `SourceLocatorDTO` và text trích xuất; không bao giờ chứa `storage_key` |
| T-02-04-D | Denial of service | oversized batch upload | high | mitigate | Giới hạn 50MB/tệp và tối đa 10 tệp/batch trên tầng API |
| T-02-04-T | Tampering | cross-site request forgery | high | mitigate | Kiểm tra đồng bộ mã CSRF token và header `X-Requested-With: RAG-Web` trên toàn bộ mutation |
</threat_model>
