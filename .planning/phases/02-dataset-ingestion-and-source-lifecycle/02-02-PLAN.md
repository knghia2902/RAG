   - Định nghĩa các mô hình ranh giới parser:
     ```python
     from typing import Any, Protocol
     from uuid import UUID
     from pydantic import Field
     from app.rag.contracts import BoundaryDTO, Position, SourceLocator

     class ParsedRecord(BoundaryDTO):
         position: Position
         locator: SourceLocator
         text: str = Field(min_length=1, max_length=32000)
         metadata: dict[str, Any] = Field(default_factory=dict)

     class ParserDiagnostic(BoundaryDTO):
         row: Position | None = None
         record_index: Position | None = None
         field: str | None = None
         reason: str = Field(min_length=1, max_length=1000)

     class ParseResult(BoundaryDTO):
         records: tuple[ParsedRecord, ...]
         diagnostics: tuple[ParserDiagnostic, ...] = ()
         is_valid: bool = True

     class UnsupportedFormatError(Exception):
         """Lỗi định dạng không hỗ trợ hoặc tệp scan không có text."""
         pass

     class MalformedSourceError(Exception):
         """Lỗi tệp nguồn hỏng hoặc sai cấu trúc cú pháp."""
         pass

     class FormatAdapter(Protocol):
         def parse_bytes(self, content: bytes, locator_base: SourceLocator, dataset_id: UUID) -> ParseResult: ...
     ```
3. Tạo file package `backend/app/rag/parsers/__init__.py`.

<files>backend/app/rag/parsers/profiles.py, backend/tests/unit/test_source_profiles.py</files>

<action>
1. Tạo `backend/app/rag/parsers/profiles.py` cài đặt 5 hồ sơ nguồn (published profiles) chuẩn hóa theo DATA-06:
   - `ProfileDefinition(BoundaryDTO)`:
     - `id: str`: định danh profile (ví dụ: `document`, `log`, `ticket`, `incident`, `operations_table`)
     - `name: str`: tên hiển thị tiếng Việt (ví dụ: `Tài liệu chung`, `Nhật ký hệ thống (Log)`, `Phiếu hỗ trợ (Ticket)`, `Sự cố (Incident)`, `Bảng dữ liệu vận hành`)
     - `description: str`: mô tả mục đích sử dụng
     - `supported_formats: tuple[str, ...]`: danh sách extension cho phép
     - `expected_fields: tuple[str, ...]`: các trường bắt buộc
     - `optional_fields: tuple[str, ...]`: các trường tùy chọn
   - 5 hồ sơ cụ thể:
     1. `document`:
        - Formats: `(".pdf", ".docx", ".txt")`
        - Expected: `()` (chỉ cần có văn bản trích xuất được)
        - Optional: `("title", "section_heading")`
     2. `log`:
        - Formats: `(".log", ".txt", ".json", ".jsonl", ".csv")`
        - Expected: `("timestamp", "system", "severity")`
        - Optional: `("order_id", "correlation_id", "error_code", "message", "trace_id")`
     3. `ticket`:
        - Formats: `(".csv", ".xlsx", ".json", ".jsonl")`
        - Expected: `("ticket_id", "system", "status", "priority", "opened_at")`
        - Optional: `("resolved_at", "assignee", "title", "description", "category")`
     4. `incident`:
        - Formats: `(".csv", ".xlsx", ".json", ".jsonl")`
        - Expected: `("incident_id", "system", "status", "priority", "created_at")`
        - Optional: `("confirmed_cause", "resolved_at", "impact_summary", "order_ids")`
     5. `operations_table`:
        - Formats: `(".csv", ".xlsx")`
        - Expected: `("entity_id", "entity_type", "status", "updated_at")`
        - Optional: `("payload", "notes")`
   - Hàm chuẩn hóa timestamp `normalize_timestamp(val: Any) -> datetime`:
     - Nhận datetime hoặc string ISO-8601 (ví dụ `2026-10-07T08:30:00Z` hoặc `2026-10-07 15:30:00+07:00`).
     - Chuẩn hóa thành timezone UTC. Nếu chuỗi naive không có múi giờ, gán UTC mặc định và lưu chuỗi gốc vào metadata.
     - Nếu không thể parse, ném lỗi kèm lý do cụ thể.
   - Hàm xác thực bản ghi `validate_records(profile_id: str, raw_records: list[dict[str, Any]]) -> tuple[list[dict[str, Any]], tuple[ParserDiagnostic, ...], bool]`:
     - Kiểm tra từng bản ghi theo thứ tự (1-indexed row/record).
     - Thu thập toàn bộ lỗi thiếu trường bắt buộc, sai định dạng timestamp, sai giá trị enum.
     - Trả về danh sách records đã chuẩn hóa, danh sách chẩn đoán lỗi `ParserDiagnostic`, và cờ `is_valid` (`False` nếu có bất kỳ lỗi trường bắt buộc nào).
2. Viết unit test hoàn chỉnh trong `backend/tests/unit/test_source_profiles.py` kiểm chứng:
   - Các trường hợp hợp lệ cho cả 5 profile chuẩn hóa đúng timestamp UTC.
   - Thiếu trường bắt buộc tạo `ParserDiagnostic` với đúng vị trí hàng `row`, tên trường `field`, và lý do `reason`.
   - Cảnh báo về trường tùy chọn không làm hỏng tính hợp lệ của nguồn nếu schema cho phép.
</action>
