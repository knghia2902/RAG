# Plan 07-01: ExtractedImage Model, Parser Extractor & Ingestion Pipeline

<threat_model>
## Security Threat Model (ASVS L1)

| Threat ID | Category | Threat Description | Mitigation Strategy |
|-----------|----------|-------------------|---------------------|
| T-07-01 | File System & Storage Tampering | File tải lên chứa mã độc hoặc cấu trúc file giả mạo làm tràn bộ nhớ, path traversal khi lưu ảnh ra đĩa | Đường dẫn lưu trữ được tạo hoàn toàn bằng UUID trên server (`storage/extracted_images/{dataset_id}/{source_version_id}/{image_id}.png`), xác thực MIME type và giới hạn kích thước tối đa qua Pillow |
| T-07-02 | Resource Exhaustion (DoS) | Tài liệu chứa hàng nghìn icon/ảnh siêu nhỏ hoặc file zip bomb làm tê liệt worker | Giới hạn số lượng ảnh tối đa trích xuất mỗi tài liệu (ví dụ: tối đa 50 ảnh/tài liệu), bỏ qua các ảnh icon quá nhỏ (< 64x64 px), kiểm soát timeout xử lý |
</threat_model>

<context>
Theo các quyết định D-01, D-02, D-07, D-09, D-10:
- **D-01 (Embedded Image Extraction):** Trích xuất tự động toàn bộ hình ảnh nhúng (diagrams, sơ đồ, ảnh chụp màn hình) trong PDF và DOCX.
- **D-02 (Rendered Page Fallback):** Đối với trang PDF scan/chụp ảnh không có selectable text (như file `2.Cài Đặt Esxi Host.pdf`), tự động render trang thành ảnh bitmap chất lượng cao (150-200 DPI) để người dùng xem được trọn vẹn tài liệu và không bị từ chối với lỗi không có text.
- **D-07 (Local Structured Storage):** Lưu ảnh cục bộ trên volume Docker theo đường dẫn phân cấp `storage/extracted_images/{dataset_id}/{source_version_id}/{image_id}.png`.
- **D-09 (Image Optimization):** Chuẩn hóa định dạng PNG/WebP, tối ưu kích thước để tiết kiệm dung lượng mà vẫn giữ độ nét cho sơ đồ và chữ kỹ thuật.
</context>

### Task 07-01-02: Image Extractor Service & Page Render Fallback
<read_first>
- `backend/app/rag/parsers/docling_adapter.py`
- `backend/app/rag/parsers/base.py`
</read_first>
<action>
Tạo `backend/app/rag/parsers/image_extractor.py`:
- Cung cấp class `ImageExtractor`:
  - `extract_from_pdf(content: bytes, dataset_id: uuid.UUID, source_version_id: uuid.UUID, output_dir: str) -> list[ExtractedImageData]`:
    - Dùng `pypdfium2.PdfDocument(io.BytesIO(content))`.
    - Lặp qua từng trang:
      - Kiểm tra xem trang có text hay không: `page.get_textpage().get_text_range().strip()`.
      - Trích xuất ảnh nhúng nếu có bằng `pypdfium2` page image objects hoặc duyệt bitmap.
      - **Fallback trang scan / chụp màn hình (D-02):** Nếu trang có rất ít hoặc không có text (< 50 ký tự) hoặc chứa hình ảnh lớn chiếm > 50% diện tích trang, tự động render toàn trang: `img = page.render(scale=2.0).to_pil()`.
      - Tối ưu kích thước (max width/height 1600px, giữ nguyên aspect ratio).
      - Lưu ảnh dạng PNG/WebP vào thư mục `output_dir/{image_id}.png`.
      - Trả về danh sách metadata: `image_id`, `page_number`, `image_type`, `storage_path`, `width`, `height`, `size_bytes`.
  - `extract_from_docx(content: bytes, dataset_id: uuid.UUID, source_version_id: uuid.UUID, output_dir: str) -> list[ExtractedImageData]`:
    - Mở `zipfile.ZipFile(io.BytesIO(content))`.
    - Quét các mục trong `word/media/` (png, jpeg, jpg, webp, wmf/emf).
    - Mở bằng Pillow, bỏ qua icon quá nhỏ (< 64x64), lưu tối ưu vào `output_dir/{image_id}.png`.
</action>
<acceptance_criteria>
- `backend/app/rag/parsers/image_extractor.py` tồn tại và định nghĩa class `ImageExtractor`.
- Có đầy đủ hai hàm `extract_from_pdf` và `extract_from_docx`.
</acceptance_criteria>
