# Plan 07-04: Frontend Image Citations, Evidence Preview & Lightbox Modal

<threat_model>
## Security Threat Model (ASVS L1)

| Threat ID | Category | Threat Description | Mitigation Strategy |
|-----------|----------|-------------------|---------------------|
| T-07-06 | Cross-Site Scripting (XSS) via Markdown Image URL | Markdown rendering trong Chat nhận URL độc hại (`javascript:...`, data URI độc) | Xử lý sanitize URL hình ảnh, chỉ cho phép URL nội bộ hợp lệ bắt đầu bằng `/api/v1/datasets/` hoặc đường dẫn an toàn đã kiểm chứng |
</threat_model>

Theo các quyết định D-05, D-06 và bản thiết kế `07-UI-SPEC.md`:

### Task 07-04-02: Create ImageLightboxModal Component
<read_first>
- `frontend/src/components/Navbar.tsx`
- `.planning/phases/07-multimodal-document-image-extraction-and-citations/07-UI-SPEC.md`
</read_first>
<action>
Tạo file `frontend/src/components/ImageLightboxModal.tsx`:
- Định nghĩa component:
  ```tsx
  interface ImageLightboxModalProps {
    isOpen: boolean;
    imageUrl: string;
    altText?: string;
    caption?: string;
    onClose: () => void;
  }
  ```
- Tính năng:
  - Lớp nền overlay mờ tối (`background: rgba(15, 23, 42, 0.85)`).
  - Đóng modal khi nhấn phím `Escape` hoặc click vào nền overlay bên ngoài.
  - State quản lý mức zoom (`scale`: mặc định 1.0, tăng giảm 0.25 mỗi lần click, min 0.5, max 3.0).
  - Thanh công cụ phía trên: Nút Zoom In (+), Nút Zoom Out (-), Nút Reset (1:1), Nút Đóng (✕).
  - Hiển thị ảnh ở giữa màn hình với `transform: scale(scale)`, cho phép cuộn để xem toàn bộ sơ đồ nếu kích thước lớn.
  - Phía dưới hiển thị chú thích `caption` hoặc tên tệp và số trang.
</action>
<acceptance_criteria>
- `frontend/src/components/ImageLightboxModal.tsx` tồn tại và export component `ImageLightboxModal`.
- Hỗ trợ đầy đủ các thao tác đóng, zoom in, zoom out, reset scale.
</acceptance_criteria>
