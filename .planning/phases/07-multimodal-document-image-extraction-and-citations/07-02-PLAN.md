# Plan 07-02: ACL-Fenced Image Serving API & Live Scope Recheck

<threat_model>
## Security Threat Model (ASVS L1)

| Threat ID | Category | Threat Description | Mitigation Strategy |
|-----------|----------|-------------------|---------------------|
| T-07-02 | Broken Access Control (Cross-Tenant/Cross-Dataset) | Người dùng thuộc dataset A đoán UUID của ảnh thuộc dataset B và tải về tài liệu nhạy cảm | Bắt buộc thực thi `verify_dataset_access(account, dataset_id, db)` và truy vấn kiểm tra ảnh phải thuộc đúng `dataset_id` được chỉ định trước khi trả file |
| T-07-03 | Stale Authorization & Token Leak | Tài khoản bị thu hồi quyền dataset nhưng vẫn tải được ảnh do URL công khai hoặc trình duyệt cache vô thời hạn | Live Scope Recheck kiểm tra trực tiếp bảng `dataset_grants` tại thời điểm gọi API; thiết lập header `Cache-Control: private, no-transform, max-age=3600` |
</threat_model>

<context>
Theo các quyết định D-08:
- **D-08 (Strict ACL-Fenced Image Serving):** Tuyệt đối không phục vụ ảnh qua URL tĩnh công khai. Mọi yêu cầu lấy ảnh phải đi qua API endpoint bảo mật:
  `GET /api/v1/datasets/{dataset_id}/sources/{source_id}/images/{image_id}`.
- Bắt buộc kiểm tra JWT authentication của `account` và kiểm tra quyền của tài khoản đối với `dataset_id` (kỹ thuật viên phải có bản ghi trong `dataset_grants`, Admin được truy cập toàn quyền).
- Áp dụng Live Scope Recheck: nếu quyền dataset của người dùng bị thu hồi trong cơ sở dữ liệu, yêu cầu tải ảnh phải lập tức trả về HTTP 403 Forbidden.
</context>

### Task 07-02-01: Secure Image Delivery Endpoint
<read_first>
- `backend/app/api/sources.py`
- `backend/app/auth/dependencies.py`
- `backend/app/database/models.py`
</read_first>
<action>
Tạo file `backend/app/api/images.py` với router FastAPI:
- Định nghĩa router: `router = APIRouter(prefix="/datasets/{dataset_id}/sources/{source_id}/images", tags=["images"])`
- Endpoint:
  ```python
  @router.get("/{image_id}")
  async def get_extracted_image(
      dataset_id: uuid.UUID,
      source_id: uuid.UUID,
      image_id: uuid.UUID,
      db: Session = Depends(get_db),
      account: Account = Depends(get_current_active_account),
  ):
  ```
- Các bước xử lý trong handler:
  1. Kiểm tra xác thực quyền dataset: gọi hàm `verify_dataset_access(account, dataset_id, db)`.
  2. Truy vấn bản ghi `ExtractedImage`:
     - Phải khớp `id == image_id` VÀ `dataset_id == dataset_id`.
     - Join với `SourceVersion` để xác nhận `source_version.source_id == source_id`.
     - Nếu không tìm thấy: raise `HTTPException(status_code=404, detail="Không tìm thấy hình ảnh.")`.
  3. Kiểm tra file vật lý trên đĩa:
     - `if not os.path.exists(image_record.storage_path):` raise `HTTPException(status_code=404, detail="Tệp hình ảnh không tồn tại trên hệ thống lưu trữ.")`.
  4. Trả về `FileResponse`:
     - `path=image_record.storage_path`
     - `media_type=image_record.mime_type`
     - `headers={"Cache-Control": "private, max-age=3600", "X-Content-Type-Options": "nosniff"}`
- Đăng ký router này vào `backend/app/main.py`.
</action>
<acceptance_criteria>
- `backend/app/api/images.py` tồn tại và định nghĩa endpoint `get_extracted_image`.
- Router được đăng ký trong `backend/app/main.py`.
</acceptance_criteria>

<action>
Tạo `backend/tests/integration/test_image_api_security.py` với các ca kiểm thử:
- `test_get_image_success_for_authorized_technician`:
  - Tạo dataset, source, source_version, và bản ghi `ExtractedImage` kèm file ảnh mẫu thực tế trong thư mục test.
  - Cấp `DatasetGrant` cho `tech_user`.
  - Gửi request `GET /api/v1/datasets/{dataset_id}/sources/{source_id}/images/{image_id}` với `tech_headers`.
  - Assert status_code == 200, Content-Type khớp mime_type của ảnh, nội dung trả về trùng khớp với file ảnh.
- `test_get_image_forbidden_for_unauthorized_dataset`:
  - Technician không được cấp quyền trên dataset B.
  - Gửi request lấy ảnh thuộc dataset B -> Assert status_code == 403 Forbidden.
- `test_live_scope_recheck_revocation`:
  - Ban đầu kỹ thuật viên có quyền và tải ảnh thành công (200 OK).
  - Thu hồi quyền trong database (`db_session.delete(grant)`).
  - Gửi lại request tải ảnh -> Assert lập tức nhận 403 Forbidden.
- `test_unauthenticated_request_rejected`:
  - Gửi request không kèm Authorization header -> Assert 401 Unauthorized.
</action>
