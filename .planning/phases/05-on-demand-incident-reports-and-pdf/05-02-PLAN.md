# Plan 05-02: WeasyPrint Docker Integration & PDF Generator Engine

<threat_model>
## Security Threat Model (ASVS L1)

| Threat ID | Category | Threat Description | Mitigation Strategy |
|-----------|----------|-------------------|---------------------|
| T-05-03 | SSRF / File Inclusion | Tấn công SSRF thông qua các thẻ `<img>` hoặc `<link>` trong template HTML biên dịch PDF | Cấu hình WeasyPrint với `url_fetcher` an toàn chặn truy cập mạng ngoài hoặc vô hiệu hóa nhúng URL ngoại bộ; toàn bộ tài nguyên hình ảnh/font nhúng cục bộ |
| T-05-04 | HTML Injection / XSS | Tên sự cố hoặc mô tả chứa mã HTML độc hại khi đưa vào template Jinja2 | Kích hoạt `autoescape=True` trong Jinja2 Environment để escape toàn bộ nội dung động trước khi render |
</threat_model>

<context>
Theo yêu cầu REP-06 và quyết định D-07, D-08:
- Sử dụng WeasyPrint 70.0 biên dịch mẫu HTML/CSS Jinja2 do ứng dụng kiểm soát sang tệp PDF A4 chuẩn in ấn.
- Nhúng bộ font tiếng Việt (`Liberation Sans`, `DejaVu Sans`) đóng gói cục bộ trong container Docker, triệt tiêu nguy cơ lỗi font tofu (ô vuông).
- Thiết lập quy tắc CSS in ấn đa trang (@page):
  - Khổ giấy A4 dọc (`size: A4 portrait; margin: 20mm 15mm 20mm 15mm;`).
  - Lặp lại tiêu đề bảng (`thead { display: table-header-group; }`) ở đầu mỗi trang mới khi bảng kéo dài nhiều trang.
  - Chống xé đôi dòng bảng (`tr { page-break-inside: avoid; }`).
  - Chân trang hiển thị số trang `Trang counter(page) / counter(pages)` cùng thời điểm xuất và mã báo cáo.
</context>

### Task 05-02-02: Jinja2 Print-Ready HTML/CSS Template for Incident Reports
<read_first>
- `.planning/phases/05-on-demand-incident-reports-and-pdf/05-CONTEXT.md`
- `.planning/phases/05-on-demand-incident-reports-and-pdf/05-RESEARCH.md`
</read_first>
<action>
Tạo `backend/app/modules/reports/templates/incident_report.html`:
- Cấu hình CSS in ấn `@page` chuẩn:
  - Khổ A4 dọc, margins 20mm trên dưới, 15mm trái phải.
  - Header: Logo / Tiêu đề "BÁO CÁO TỔNG HỢP SỰ CỐ IT & LOGISTICS".
  - Footer: Bên trái hiển thị "Logistics RAG · Báo cáo vận hành IT & Logistics", bên phải hiển thị `"Trang " counter(page) " / " counter(pages)`.
  - CSS cho bảng: `table { width: 100%; border-collapse: collapse; } thead { display: table-header-group; } tr { page-break-inside: avoid; }`.
  - Font-family: `'Liberation Sans', 'DejaVu Sans', sans-serif`.
- Nội dung template bao gồm các section:
  1. *Thông tin chung:* Mã báo cáo, Kỳ báo cáo, Khoảng thời gian (UTC+7), Thời điểm xuất bản, Tài khoản tạo.
  2. *Chỉ số KPI chính:* Bảng thẻ tổng hợp (Tổng sự cố, Tổng ticket, Đang mở, Đã hoàn tất, MTTR trung bình).
  3. *Phân bổ theo hệ thống & mức ưu tiên:* Bảng tỷ lệ WMS, TMS, API Gateway và P1-P4.
  4. *Danh sách lỗi lặp lại:* Bảng hệ thống, mã lỗi, số lần xuất hiện và danh sách đơn hàng bị ảnh hưởng.
  5. *Nhận định xu hướng & Khuyến nghị SOP:* Khối nhận định tự động của AI và các bước xử lý theo SOP.
  6. *Snapshot nguồn dữ liệu (Provenance):* Danh sách dataset và tên tệp/phiên bản nguồn tham chiếu.
</action>
<acceptance_criteria>
- File `backend/app/modules/reports/templates/incident_report.html` tồn tại và chứa đầy đủ cấu trúc `@page`, `counter(page)`, `table-header-group`, và `page-break-inside: avoid`.
- Không sử dụng bất kỳ link font hoặc CSS ngoại bộ nào từ internet trong template.

### Task 05-02-03: WeasyPrint PDF Generator Service & Unit Tests
<read_first>
- `backend/app/modules/reports/templates/incident_report.html`
- `backend/app/modules/reports/contracts.py`
</read_first>
<action>
Tạo `backend/app/modules/reports/pdf_generator.py`:
- Lớp `ReportPDFGenerator`:
  - Khởi tạo Jinja2 `Environment` với `FileSystemLoader` trỏ tới thư mục `templates/`, cấu hình `autoescape=True`.
  - Phương thức `render_html(report_data: ReportDetailDTO) -> str`: Điền dữ liệu báo cáo vào template.
  - Phương thức `generate_pdf(report_data: ReportDetailDTO) -> bytes`: Biên dịch HTML sang PDF bytes bằng `weasyprint.HTML(string=html_content).write_pdf()`.
Tạo `backend/tests/unit/test_pdf_generator.py`:
- `test_render_html_escaping`: Kiểm tra Jinja2 tự động escape các ký tự đặc biệt `<`, `>`, `&`.
- `test_generate_pdf_magic_bytes`: Kiểm tra kết quả trả về là `bytes` bắt đầu bằng `%PDF-1.`.
- `test_generate_pdf_vietnamese_characters`: Kiểm tra hiển thị đầy đủ các chuỗi ký tự tiếng Việt có dấu phức tạp ("Hệ thống quản lý kho vận Sóng Thần", "Lỗi mất đồng bộ trạng thái WMS - TMS") mà không gây lỗi font hay encoding.
Chạy pytest đảm bảo 100% tests vượt qua.
</action>
