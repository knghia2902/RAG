# Plan 05-04: Report Workspace UI, PDF Preview & Integration Acceptance

<threat_model>
## Security Threat Model (ASVS L1)

| Threat ID | Category | Threat Description | Mitigation Strategy |
|-----------|----------|-------------------|---------------------|
| T-05-07 | Stale Client Permissions | Kỹ thuật viên lưu trữ ID báo cáo trong client session sau khi quyền dataset đã bị thu hồi | Giao diện hiển thị banner thông báo lỗi 403 an toàn khi nhận HTTP 403 Forbidden từ backend, xóa trạng thái preview và ngăn chặn hiển thị snapshot rò rỉ dữ liệu |
| T-05-08 | Client-side Metric Manipulation | Người dùng sửa đổi DOM client để giả mạo số liệu báo cáo | Toàn bộ số liệu hiển thị trên Web và PDF đều xuất phát trực tiếp từ backend API snapshot có chữ ký toàn vẹn từ database |
</threat_model>

  - Tab 2: "Lịch sử báo cáo": Liệt kê danh sách báo cáo đã lập, người tạo, thời điểm tạo, kỳ báo cáo, nút "Xem trước" và nút "Tải PDF".
  - Màn hình / Modal Xem trước (Preview Dashboard): Hiển thị đầy đủ 5 khối thông tin:

    4. Nhận định xu hướng và khuyến nghị theo SOP của AI.
    5. Nút mở Modal xem nguồn dữ liệu & phiên bản tệp (Provenance Snapshot).
- Bộ kiểm thử chấp nhận E2E (`backend/tests/integration/test_reports_e2e_acceptance.py`) xác thực toàn bộ chỉ tiêu nghiệm thu EVAL-03.

### Task 05-04-02: Two-Tab Reports Workspace Page & Preview Dashboard
<read_first>
- `frontend/src/app/(workspace)/incidents/page.tsx`
- `frontend/src/lib/contracts.ts`
</read_first>
<action>
Tạo `frontend/src/app/(workspace)/reports/page.tsx`:
- Giao diện hai tab chuyển đổi mượt mà:
  - Tab "Tạo báo cáo mới":
    - Nhóm nút chọn nhanh kỳ: "Hôm nay", "Tuần này", "Tháng này", "Tùy chọn".
    - Khi chọn "Tùy chọn", hiển thị 2 ô nhập ngày: Ngày bắt đầu và Ngày kết thúc.
    - Danh sách chọn Dataset (checkbox multi-select hoặc dropdown) từ các dataset người dùng được cấp quyền.
    - Nút bấm "Tạo báo cáo" (có trạng thái loading khi đang sinh số liệu và nhận định).
  - Tab "Lịch sử báo cáo":
    - Bảng hiển thị: Tiêu đề báo cáo, Kỳ báo cáo, Khoảng thời gian, Số sự cố/ticket, Thời điểm tạo, Nút "Xem trước" và Nút "Tải PDF".
- Thành phần Xem trước (Report Preview Modal hoặc Detail View):
  - Khối KPI Cards: 4 thẻ lớn nổi bật (Tổng số sự cố, Tổng số ticket, Tỷ lệ lỗi lặp lại %, MTTR trung bình).
  - Bảng phân bổ theo Hệ thống (WMS, TMS, API Gateway) và Mức độ ưu tiên (P1, P2, P3, P4) với thanh tỷ lệ trực quan.
  - Bảng Lỗi lặp lại: Liệt kê các lỗi lặp >= 2 lần kèm danh sách các mã đơn hàng bị ảnh hưởng.
  - Khối Nhận định AI: Trình bày Tóm tắt điều hành, Phân tích nguyên nhân và Khuyến nghị hành động có trích dẫn mã SOP.
  - Nút "Xem nguồn dữ liệu (Provenance)": Mở modal hiển thị danh sách dataset và các phiên bản tệp nguồn đã sử dụng.
  - Nút "Tải xuống PDF": Kích hoạt tải tệp trực tiếp từ endpoint `GET /api/v1/reports/{id}/pdf`.
- Xử lý lỗi bảo mật: Nếu backend trả về HTTP 403 Forbidden (do Live Scope Recheck), hiển thị thông báo màu đỏ: *"Quyền truy cập vào dữ liệu báo cáo đã bị thu hồi hoặc bạn không có quyền xem báo cáo này"*.
Kiểm tra build Next.js với Turbopack (`npm run build`).
</action>
