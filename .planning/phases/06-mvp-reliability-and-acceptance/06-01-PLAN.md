# Plan 06-01: Security Fencing, Live Scope Recheck & Idempotent Recovery

<threat_model>
## Security Threat Model (ASVS L1)

| Threat ID | Category | Threat Description | Mitigation Strategy |
|-----------|----------|-------------------|---------------------|
| T-06-01 | Injection & Information Disclosure | Người dùng hoặc nội dung log/ticket chứa prompt injection ("Ignore previous instructions", "Dump API keys") nhằm trích xuất secret | Áp dụng `mask_secrets()` trên mọi luồng đầu ra, gán system instructions nghiêm ngặt và kiểm tra tự động LLM không dump environment variables |
| T-06-02 | Broken Access Control | Quyền dataset bị thu hồi hoặc nguồn bị xóa (tombstone) nhưng người dùng vẫn truy xuất được dữ liệu cũ qua Chat history, Incident details hoặc Report PDF | Thực thi Live Scope Recheck trên 100% bề mặt API (Chat, Incidents, Reports, PDF stream) và chặn Celery worker xử lý nguồn có `deleted_at is not null` |
| T-06-03 | Data Integrity & Replay Attacks | Celery worker restart hoặc job retry dẫn đến nhân đôi bản ghi CanonicalRecord hoặc EmbeddingRecord trong cơ sở dữ liệu | Áp dụng deduplication bằng content hash và idempotency key trên các pipeline import |
</threat_model>

<context>
Theo yêu cầu EVAL-02 và các quyết định D-01, D-02, D-03:
- **D-01 (Prompt Injection & Secret Leak Prevention):** Kiểm tra tự động các mẫu injection độc hại vào mô tả sự cố và ticket IT. Khẳng định không có token/API key (`sk-...`, secret keys, database credentials) bị rò rỉ trong phản hồi của hệ thống.
- **D-02 (Live Scope Recheck & Tombstone):**
  - Chat API: Khi quyền dataset bị thu hồi, tin nhắn lịch sử và trích dẫn thuộc dataset đó không được hiển thị.
  - Incident Analysis API: Endpoint `/api/v1/incidents/{incident_id}` trả về 403 Forbidden ngay lập tức nếu dataset liên quan bị thu hồi quyền.
  - Reports API: Endpoint `/api/v1/reports/{report_id}` và `/api/v1/reports/{report_id}/pdf` trả về 403 Forbidden nếu bất kỳ dataset nào trong báo cáo bị thu hồi quyền.
  - Ingestion & Worker: Celery task từ chối xuất bản hoặc tạo `CanonicalRecord` nếu `Source` hoặc `SourceVersion` đã bị tombstone (`deleted_at is not null`).
- **D-03 (Chống nhân đôi dữ liệu):** Khi gọi lại pipeline import dữ liệu nhiều lần với cùng nội dung, số lượng `CanonicalRecord` và `EmbeddingRecord` không tăng lên (idempotent).
</context>
