| Threat ID | Category | Threat Description | Mitigation Strategy |
|-----------|----------|-------------------|---------------------|
| T-06-08 | Hardcoded Secrets in Scripts & Docs | Script demo walkthrough hoặc tài liệu Runbook vô tình chứa secret key hoặc mật khẩu thật của production | Sử dụng biến môi trường chuẩn (`ADMIN_PASSWORD`, `TECH_PASSWORD`) và cảnh báo rõ ràng trong tài liệu về việc thay đổi mật khẩu mặc định sau khi cài đặt |

### Task 06-04-02: Operations Runbook Documentation
<read_first>
- `docker-compose.yml`
- `backend/Dockerfile`
- `README.md`
- `.planning/phases/06-mvp-reliability-and-acceptance/06-CONTEXT.md`
</read_first>
<action>
Tạo file `docs/runbook.md` gồm các phần chi tiết:
1. **Kiến trúc triển khai Local Docker Compose:**
   - Sơ đồ các service: `postgres` (pgvector), `rabbitmq`, `migrate`, `backend`, `celery_worker`, `frontend`.
   - Các cổng truy cập mặc định: Frontend (3000), Backend API (8000), PostgreSQL (5432).
2. **Hướng dẫn cài đặt & Khởi động nhanh:**
   - Cấu hình file `.env` (DATABASE_URL, OPENAI_API_KEY, SECRET_KEY, CELERY_BROKER_URL).
   - Lệnh khởi động: `docker compose up -d`.
   - Lệnh kiểm tra trạng thái: `docker compose ps` và healthcheck endpoints.
3. **Vận hành & Giám sát hàng ngày:**
   - Theo dõi log: `docker compose logs -f backend celery_worker`.
   - Khởi tạo dữ liệu demo 1 lệnh: `docker compose exec backend python scripts/demo_walkthrough.py`.
   - Chạy test kiểm thử tự động: `docker compose run --rm backend-test pytest`.
4. **Quy trình xử lý sự cố (Disaster Recovery & Troubleshooting):**
   - Sự cố Worker Celery crash hoặc nghẽn hàng đợi: Cách thu hồi lease, giải phóng task bị treo, và restart worker.
   - Sự cố mất kết nối database / transaction rollback: Cách kiểm tra migration status với Alembic.
5. **Quy trình Tái lập chỉ mục Vector (Zero-Downtime Reindexing):**
   - Hướng dẫn chuyển đổi embedding model (ví dụ từ `text-embedding-3-small` sang mô hình khác).
   - Cách tạo `index_version` mới, embed song song, chuyển pointer hệ thống, và dọn dẹp vector cũ.
6. **Bảng công bố giới hạn vận hành thực tế:**
   - Kích thước tệp tối đa: 10MB.
   - Thời gian timeout yêu cầu: 30s.
   - Mức tải Celery worker đồng thời: Concurrency = 2.
   - Bảng độ trễ đo được thực tế (p50 / p95) từ harness benchmark.
</action>
