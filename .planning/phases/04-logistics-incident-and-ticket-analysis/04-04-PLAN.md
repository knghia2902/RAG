<threat_model>
### Threat Assessment (ASVS L1)
- **T-04-07 (Insecure Direct Object Reference - IDOR on Incident Analyses):** Người dùng có thể đoán hoặc duyệt UUID của `analysis_id` để xem nội dung phân tích sự cố thuộc các dataset mà tài khoản không được cấp quyền.
  - *Mitigation:* Bắt buộc kiểm tra quyền sở hữu (`account_id == current_user.account_id` hoặc role `admin`), đồng thời chạy `policy.recheck_response()` đối soát toàn bộ dataset id liên quan; nếu vi phạm, trả về HTTP 403/404 an toàn.
- **T-04-08 (Resource Exhaustion via Unbounded Log Queries):** Kỹ thuật viên nhập order ID rỗng hoặc regex rộng làm quét toàn bộ hàng triệu dòng log gây nghẽn database.
  - *Mitigation:* Validate độ dài `order_id` tối thiểu 3 ký tự, chỉ chứa ký tự chữ và số (`^[A-Za-z0-9_-]+$`); giới hạn kết quả log tối đa 200 bản ghi mỗi lượt phân tích.
</threat_model>
